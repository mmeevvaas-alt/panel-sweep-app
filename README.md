# ניתוח סריקות פאנל סולארי (Panel sweep analysis)

אפליקציה שפותחים בדפדפן: מעלים את קובצי ה-ZIP שמגיעים מ-`panel_sweep.py`, והיא מציגה אוטומטית:

1. **פרטי הניסוי** מתוך `settings.txt` (כולל הודעת `RUN STOPPED`), וכיסוי ואיכות הנתונים.
2. **פאזה, הגבר ומתח DC במוצא מול תדר** (ציר תדר לוגריתמי), עם בחירה של כמה אורכי גל וכמה מתחי DC יחד.
3. **פאזה מול אורך גל** בתדר ובמתח לבחירה.
4. **ניתוח ההבדלים בפאזה בין אורכי הגל** בכל מצב מדידה (תדר + מתח), דירוג המצבים והסבר כתוב.
5. ברירת המחדל של גרף 3 = המצב עם ההבדלים הגדולים ביותר, ומתחתיו **הנגזרת dφ/dλ**.
6. **האימפדנס של הפאנל Z(ω)** מתוך H = R_L/(R_L+Z), התאמה של מודל מעגל שקול לכל אורך גל ומתח, ומידת ההתאמה.

אפשר להעלות כמה ZIP יחד (למשל ריצת לילה + ריצת בוקר). באורך גל שמופיע ביותר מריצה אחת נלקחים
הנתונים מהריצה **המאוחרת** שבה אורך הגל נמדד במלואו.

## התקנה (פעם אחת)

1. שימי את כל הקבצים בתיקייה אחת, למשל `C:\Users\LAB\Documents\panel_app`.
2. לחיצה כפולה על `install.bat`, או ב-PowerShell מתוך התיקייה:
   ```
   python -m pip install -r requirements.txt
   ```
   זה מתקין: streamlit, pandas, numpy, scipy, matplotlib.

## הפעלה

1. לחיצה כפולה על `run_app.bat`, או ב-PowerShell מתוך התיקייה:
   ```
   python -m streamlit run app.py
   ```
2. נפתחת לשונית בדפדפן (בכתובת `http://localhost:8501`).
3. בסרגל הצד: **Browse files** ← בוחרים ZIP אחד או יותר.
4. עוברים בין הלשוניות למעלה. כל גרף אפשר להוריד כ-PNG, והנתונים המעובדים בלשונית "הורדות".
5. לסגירה: סוגרים את חלון ה-PowerShell (או Ctrl+C בתוכו).

## הגדרות בסרגל הצד

- **R_L** – נגד העומס (ברירת מחדל 1000 Ω). אפשר לכלול גם את כניסת הסקופ (1 MΩ) במקביל.
- **סף אמינות** – אמפליטודה מינימלית בערוץ 2 (ברירת מחדל 10 mV). מתחתיו הנקודה מסומנת בעיגול חלול,
  ולא נכנסת להתאמת המודל. בנתוני 9–10/11 נמצא שמתחת לסף הזה האמפליטודה תלויה בסקאלת הסקופ.
- **מוסכמת פאזה** – ברירת המחדל היא הפאזה הפיזיקלית של V2/V1 = ‎−phase_deg של הסקופ
  (ערך חיובי = הזרם מקדים את המתח, כמו בקבל). אפשר להציג את הערך הגולמי.
- **שיטת הדירוג** של "הבדלים גדולים בין אורכי גל":
  - *טווח, רק מצבים אמינים* (ברירת מחדל) – מקס' פחות מינ', בלי מצבים שיש בהם נקודות עם אות חלש;
  - *טווח, כל המצבים* – כולל התדרים הנמוכים הרועשים;
  - *מובהקות* – פיזור בין אורכי הגל ביחס לרעש הנקודתי;
  - *מגמה שיטתית* – כמה מהפיזור מוסבר בעקומה חלקה.

## איך מחושבים הדברים

- הגבר = ch2_amplitude / ch1_amplitude (מול ערוץ 1 הנמדד, לא מול 1 V נומינלי).
- זרם DC = ch2_dc / R_L.
- Z(ω) = R_L·(V1/V2 − 1) בפאזורים, מכל נקודה בנפרד.
- **רעש נקודתי** בין אורכי גל = std של ההפרשים בין אורכי גל סמוכים / √2. אם סטיית התקן בין אורכי הגל
  דומה לרעש הנקודתי (יחס ≈ 1), ההבדלים נראים כמו פיזור אקראי.
- **הנגזרת dφ/dλ** מחושבת מהתאמה ריבועית מקומית בחלון (ברירת מחדל 25 nm). הקו הדק = נגזרת בלי החלקה.
- **מודלים ל-Z**: R‖C; Rs + R‖C; Rs + R‖CPE; Rs + R1‖C1 + R2‖C2 (ברירת מחדל); וזה עם השראות Ls בטור.
  ההתאמה ממזערת את השגיאה היחסית בהגבר ואת השגיאה בפאזה של H.

- `python` לא מזוהה ← לנסות `py` במקום `python`.

  אפשר להתקין Python 3.13 במקביל ולהריץ עם `py -3.13 -m pip install -r requirements.txt`
  ו-`py -3.13 -m streamlit run app.py`.
- הדפדפן לא נפתח ← לפתוח ידנית את `http://localhost:8501`.
